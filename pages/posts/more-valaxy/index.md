## 前言
博客已经完成大部分工作了，先具体介绍一下我的搭建思路，因为考虑成本原因，选择了静态页面部署。

部署方案是 Github Pages(代码托管) + Valaxy(博客代码) + 域名 + CDN(加速)

方案翻译：存储桶 + 博客代码 + 域名 + 缓存(CDN)

博主考虑过使用云服务存储桶的，毕竟现在的访问加载慢仍然是大问题，不过存储桶没有自动化部署流程，在修改文章的时候比较麻烦。

现在仍然使用github pages进行部署。

## 需求分析

博客运行了一段时间了，但每次访问浏览器都会提醒不安全，没有ssl证书。

博主决定将证书安排上，用上奢侈的https协议。

非常痛心！七牛云https流量没有免费额度。现在转其他平台也挺麻烦的，所以博主开始付费使用了。

## 部署环节

#### 找一个ssl证书
可以选择的平台非常多，大平台应该都有免费的ssl证书。

我这里选择的是阿里云(三个月)免费版。

大概步骤：进入控制台-->进入ssl管理界面-->购买证书-->申请证书(DNS手动验证：需要去域名解析界面，解析一下TXT记录才能申请成功)

#### 七牛云配置https服务

https流量需要付费，不过挺便宜的。(博主一开始就用七牛云就懒得换了，大家可以找有免费额度)

大概步骤：进入控制台-->进入加速域名管理-->修改之前的加速域名-->打开https服务(需要上传准备好的ssl证书)

#### github pages配置https服务

大概步骤：进入项目-->设置-->GitHub Pages-->选择https服务

## 总结一下

Valaxy 博客 HTTPS 升级的操作步骤比较简单。

核心成本仅为七牛云 HTTPS 流量费用，目前每月实际开销约 0.01 元人民币(博客没有访问量)，就用上了https服务。
