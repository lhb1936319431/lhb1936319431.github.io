## Valaxy
博客部署成功了，接下来开始新的牛马人生。

## 简单记录博客搭建过程

#### 需求分析

因为需要使用到Github Pages进行部署并托管，我们就需要找静态网站的开源博客框架。

推荐两个用过的：

- **Hexo**：轻量级且高效，支持Markdown，快速渲染页面，易于部署。

- **Valaxy**：一款创新的、面向未来的静态博客框架。

在这里选择的是 "Valaxy+云游君主题" 进行博客搭建。

#### 搭建步骤

1. 准备好环境（挺简单的直接去[ node 中文网](https://nodejs.cn/download)下载)
   - 要求  Node.js  的版本为 `^20.19.0 || >=22.12.0`


2. 在电脑里找一个安静的角落打开 CMD 输入命令

```shell
npm init valaxy #我选择的是 Blog 和 yarn 组合
```

3. 根据自己心情对博客进行微调
   - 在 site.config.ts 和 valaxy.config.ts 里面调整。


4. 需要对博客部署托管 （有很多免费方案）

   - 选择 Github Pages 最好安装 vs code+git 可以快速提交代码，提交代码可能超时需要耐心等待。

   - 具体方法可以搜索Github Pages教程。
